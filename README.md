# NFL Analytics Engineering Platform

An end-to-end data engineering project using NFL play-by-play data to explore team performance, player statistics, and game strategy.

## Objectives

- Ingest public NFL data using Python.
- Process and validate data with PySpark.
- Store analytical data in Snowflake.
- Build tested, documented data models with dbt.
- Orchestrate pipeline tasks using Apache Airflow.
- Apply version control, automated testing, and CI/CD practices.

## Planned Architecture

NFL data → Python ingestion → PySpark processing → Snowflake → dbt → Analytics

Apache Airflow will orchestrate the pipeline, while GitHub Actions will support automated testing.

## Project Status

**In progress.** The repository and initial project structure have been created. Pipeline components will be added and documented as they are implemented.

## Technology Stack

Python · PySpark · Apache Airflow · Snowflake · dbt · Git · GitHub Actions
